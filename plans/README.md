## Dependency notes

- Plan 001 creates the fixture vocabulary used by all later plans.
- Plan 002 fixes the monetary model before ranking behavior is changed.
- Plan 003 makes substitution eligibility explicit before Plan 005 expands
  candidate retrieval.
- Plan 004 can be implemented after Plan 001, but must precede the final
  output-contract work in Plan 005.

## Deferred direction

- A cross-store trip optimizer and `recommend <need>` command are intentionally
  deferred. They must build on the corrected cost and constraint model rather
  than duplicating today's fractional-pack semantics.
- Automatic basket replacement is out of scope. Any future implementation must
  remain proposal-only unless `--yes` is supplied, use absolute quantities,
  never retry writes, and respect reserved-slot deadlines.
